# rs2-worker — RS2 on Cloudflare Workers

The TypeScript host of the RS2 HTTP API: one stateless Worker in front of
one `TenantObject` Durable Object per tenant (R2 for files, DO SQLite for
data/idempotency/logs) plus a single `RegistryObject` for the operator
table. The spec is `docs/agents/cloudflare.md`; this file is the operator's
card. Phase status: **P2** (store contract) plus the pipeline executor
(`pipeline` and `wrapper` execute; `src/pipeline/*`, jsonata) — `query`/
`template` execution, `proxy`, `sms`, and `code:` invocation answer 501
until P3/P4.

```sh
npm ci
cp .dev.vars.example .dev.vars      # RS2_ADMIN_TOKEN for /admin/*
npm run dev                         # wrangler dev on http://127.0.0.1:8787
npm test                            # vitest (@cloudflare/vitest-pool-workers)
npm run typecheck
```

`wrangler dev` provides local R2, SQLite DOs, alarms, cron
(`curl http://127.0.0.1:8787/cdn-cgi/local/scheduled`), and the
`worker_loaders` binding (verified working locally with wrangler 4.126).

## Provision a tenant

Every tenant request routes `Host` → tenant → `TenantObject`. With the
default `RS2_DEFAULT_TENANT=main` any host maps to `main` until a tenant is
created; the admin API (spec §B.5, gated by `RS2_ADMIN_TOKEN`) creates it:

```sh
curl -X PUT -H "authorization: Bearer dev" -H "content-type: application/json" \
  http://127.0.0.1:8787/admin/tenants/main \
  --data '{"config": {"auth": {"jwtSecret": "s3cret", "userDataset": "users"}, "operatorRoles": "A",
                       "mounts": [{"path": "/files", "service": "file", "config": {"access": "open"}},
                                  {"path": "/services", "service": "services", "config": {"access": {"read": "A", "write": "A"}}},
                                  {"path": "/auth", "service": "auth", "config": {"access": "open"}}]},
           "domains": ["api.example.test"],
           "bootstrapAdmin": {"email": "admin@example.test", "password": "pw"}}'
```

`GET /admin/tenants`, `GET|DELETE /admin/tenants/<name>` (`?confirm=<name>`),
`PUT|DELETE /admin/domains/<host>`, `PUT /admin/infras`, and
`POST /admin/reload-infras` complete the surface.

## Layout

```
src/index.ts              fetch (ops, admin, resolve, forward), scheduled (fan-out)
src/registry-object.ts    RegistryObject DO (domain map, tenant list, infras)
src/tenant-object.ts      TenantObject DO: Request↔Message, config KV, RPC, alarms stub
src/runtime/              ports of rs2-core: error message body media-type router
                          path-pattern wrapper dispatch tenant-build infra config-schema
                          listing logging idempotency scheduler outbound retry crypto discovery
src/capabilities/         types prefixed scoped r2-file-store sqlite-data-store
                          sqlite-idempotency sqlite-log-store fetch-http-out credential
                          builtin-registry
src/services/             context file data spec-store pipeline-service wrapper-service
                          services-config log-reader auth catalogue code schema stubs
src/pipeline/             spec dsl condition transform response segments executor
src/fixtures/catalogue.json  generated by the Rust side (see below)
src/vendor/hash-wasm/     argon2id/bcrypt with precompiled .wasm (see below)
test/                     unit tests ported from the rs2-core #[cfg(test)] modules
```

## Generated inputs

- **`src/fixtures/catalogue.json`** is `config_schema::catalogue()` as the
  Rust host emits it (`cargo run -p rs2-cli -- catalogue-dump`, the same
  document as `conformance/http/fixtures/catalogue.json`). Regenerate it
  whenever `rs2-core/src/config_schema.rs` changes so the two hosts cannot
  drift.
- **`src/vendor/hash-wasm/`** is the argon2id/bcrypt/blake2b slice of
  `hash-wasm` (MIT) with its Wasm binaries extracted to importable `.wasm`
  modules: Workers forbid `WebAssembly.compile` at runtime, which is how
  the npm package loads its embedded base64. Regenerate with
  `npm run vendor:hash-wasm` after bumping the `hash-wasm` devDependency.

## Conformance

The black-box runner lives in `conformance/http/`:

```sh
cd conformance/http
RS2_PORT=8787 RS2_ADMIN_TOKEN=dev npm run host:cf       # terminal 1
RS2_HOST_KIND=cloudflare RS2_PORT=8787 RS2_ADMIN_TOKEN=dev npm test   # terminal 2
```
